About us

Who this project is for and how it was built.

Python, With Depth was designed as a student project that presents Python in a way that feels useful, approachable, and visually intentional.

Project team

The site is framed as a small editorial studio project. It introduces Python, explains why people keep using it, and packages ideas into pages that are easy to browse.

What we focused on

  • Clear content hierarchy with a readable article-style layout
  • Responsive design for desktop, tablet, and mobile screens
  • A product grid that presents themed Python learning kits
  • Simple forms that fit the site and meet the assignment requirements

Structure

How the website is organized

The intro page acts as the main text-driven page type. The learning kits page acts as the raster page, where items are displayed in a grid and link to separate detail pages.

Design choices

Visual direction

Warm gradients, rounded cards, and editorial typography give the project a distinct look while still keeping navigation and content easy to scan.

Built for the web design assignment with separate content, grid, and form pages.
