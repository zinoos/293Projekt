## Projektbeschreibung

This project is a multi-page website about Python as a language, learning path, and creative toolset. It combines an editorial intro page, an about page, a product-style grid, detail pages, and simple user forms in a responsive layout built with HTML, CSS, and JavaScript. The visual direction mixes warm print-inspired colors with structured cards to make the site feel both informative and designed.
