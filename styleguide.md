# Styleguide

## Logo

- The site uses `Logo.png` as the main brand mark in the header.
- It stays visible across all pages to keep the project identity consistent.

## Color Scheme

- Background: soft rose and blush tones for the light theme.
- Accent colors: deep berry, warm apricot, and Python-inspired blue in the dark theme.
- Surfaces: layered translucent panels with subtle borders and shadows.

## Typography

- Headings use `Fraunces` for a more editorial, expressive tone.
- Body text uses `Space Grotesk` for readable modern sans-serif text.
- Labels and code samples use `IBM Plex Mono` for technical contrast.

## Spacing and Layout

- Large sections use generous vertical spacing to separate content clearly.
- Cards and panels use rounded corners and consistent padding.
- The main page structure relies on flexible content blocks, while the products overview uses a CSS Grid layout for the raster requirement.
